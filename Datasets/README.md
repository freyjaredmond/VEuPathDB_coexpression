# The RNA-seq datasets used in this analysis

All RNA-seq datasets for the reference strains of Aspergillus fumigatus, Aspergillus nidulans, Anopheles gambiae, Candida auris, Plasmodium berghei, Plasmodium falciparum and Toxoplasma gondii were taken from VEuPathDB (release 71) (Table 1) Expression values were taken as transcripts per million (TPM), using uniquely mapped reads and sense-strand counts where available. Datasets with <2 samples were excluded.
