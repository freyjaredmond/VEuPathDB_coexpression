# RNA-seq datasets used in this analysis

All available RNA-seq datasets for the reference strains of *Aspergillus fumigatus*, *Aspergillus nidulans*, *Anopheles gambiae*, *Candida auris*, *Plasmodium berghei*, *Plasmodium falciparum* and *Toxoplasma gondii* were obtained from VEuPathDB (release 71; Table 1). Expression values were taken as transcripts per million (TPM), using uniquely mapped reads and sense-strand counts where available. Datasets with fewer than two samples were excluded.

**Table 1: VEuPathDB RNA-seq datasets used for each genome**

| Organism | Strain | Datasets (n) | Samples (n) |
|---|---|---:|---:|
| *Aspergillus fumigatus* | Af293 | 15 | 85 |
| *Aspergillus nidulans* | FGSC A4 | 6 | 22 |
| *Anopheles gambiae* | PEST | 17 | 101 |
| *Candida auris* | B8441 | 6 | 42 |
| *Plasmodium berghei* | ANKA | 7 | 69 |
| *Plasmodium falciparum* | 3D7 | 27 | 285 |
| *Toxoplasma gondii* | ME49 | 22 | 122 |
